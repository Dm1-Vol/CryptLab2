# LSB Steganography with AES-256-GCM

## Описание проекта

Проект посвящён исследованию методов стеганографии на основе Least Significant Bit (LSB).

Реализованы три способа встраивания текстовых сообщений в изображения:

1. **Plain LSB** — встраивание открытого сообщения в младшие биты RGB-компонент.
2. **Encrypted LSB** — предварительное шифрование сообщения с помощью AES-256-GCM и последовательное встраивание полученного шифротекста.
3. **Encrypted Random LSB** — шифрование сообщения и встраивание данных в псевдослучайно выбранные позиции.

Шифрование обеспечивает конфиденциальность содержимого сообщения, а стеганография позволяет скрыть сам факт наличия сообщения внутри изображения.

Важно: шифруется только полезная нагрузка, а не всё изображение. Исходное изображение сохраняет практически неизменный внешний вид.

## Возможности

- Встраивание и извлечение текстовых сообщений методом LSB.
- Шифрование и расшифрование с использованием AES-256-GCM.
- Получение ключа из пароля с помощью PBKDF2-HMAC-SHA256.
- Последовательное и псевдослучайное размещение данных.
- Сравнение трёх методов стеганографии.
- Эксперименты с различным объёмом скрываемых данных.
- Вычисление метрик качества изображений.
- Статистический анализ младших битов.
- Построение гистограмм и карт различий.

## Установка

Клонировать репозиторий:

```bash
git clone <REPOSITORY_URL>
cd StegoCrypto
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его в Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск проекта

### 1. Тестирование LSB

```bash
python test_lsb.py
```

Проверяется корректность встраивания и извлечения сообщения для исходных изображений.

### 2. Тестирование шифрования и стеганографии

```bash
python test_crypto.py
```

Проверяется работа зашифрованного и псевдослучайного вариантов встраивания.

### 3. Основной эксперимент

```bash
python run_experiment.py
```

Сравниваются три метода на изображениях `gradient.png` и `map.png`.

Результаты сохраняются в каталоге `results/`, а метрики — в `results/metrics.csv`.

### 4. Эксперимент с объёмом сообщения

```bash
python run_volume_experiment.py
```

Проводится сравнение методов при заполнении приблизительно 1% и 5% доступных RGB-компонент изображения `gradient.png`.

Результаты сохраняются в `results/`, а таблица метрик — в `results/volume_metrics.csv`.

### 5. Дополнительный анализ

```bash
python inspect_results.py
```

Создаются дополнительные графики распределения цветовых компонент и различий гистограмм.

## Алгоритмы и параметры

### Шифрование

Для защиты сообщения используется AES-256-GCM.

Ключ выводится из пароля с помощью PBKDF2-HMAC-SHA256.

Параметры:

| Параметр | Значение |
|---|---:|
| Размер ключа | 256 бит |
| Размер соли | 16 байт |
| Размер nonce | 12 байт |
| Размер тега аутентификации | 16 байт |
| Итерации PBKDF2 | 600 000 |

Соль и nonce генерируются случайно при каждом шифровании.

### Встраивание

Перед полезной нагрузкой записывается 4-байтовый заголовок с её длиной.

В последовательном варианте данные размещаются в младших битах RGB-компонент по порядку.

В псевдослучайном варианте используется перестановка позиций, воспроизводимая при извлечении.

## Метрики

Для оценки качества модифицированных изображений используются:

- **MSE** — среднеквадратичная ошибка.
- **PSNR** — пиковое отношение сигнала к шуму.
- **SSIM** — структурное сходство.
- **Changed components** — количество изменённых RGB-компонент.
- **Changed ratio** — доля изменённых компонент.
- **LSB distribution** — распределение нулей и единиц в младших битах.
- **Chi-square test** — статистический тест на различие частот пар значений 2k и 2k+1.

## Ограничения

Псевдослучайный выбор позиций предназначен для экспериментального сравнения и не является самостоятельным криптографическим механизмом.

Конфиденциальность сообщения обеспечивается AES-256-GCM.

Критерий хи-квадрат является одним из способов статистического анализа и не представляет собой универсальный метод обнаружения стеганографии.

## Вывод

Проект демонстрирует сочетание криптографического шифрования и LSB-стеганографии. Эксперименты позволяют исследовать влияние шифрования, выбора позиций и объёма полезной нагрузки на визуальные и статистические характеристики изображений.
