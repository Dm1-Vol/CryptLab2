# StegoCrypto — LSB Steganography

Учебный проект по исследованию методов сокрытия информации в изображениях с использованием **LSB-стеганографии** (Least Significant Bit).

Реализованы три варианта встраивания сообщения:

1. **Plain LSB** — последовательное встраивание открытого сообщения.
2. **Encrypted LSB** — шифрование сообщения с последующим последовательным встраиванием.
3. **Encrypted Random LSB** — шифрование сообщения и встраивание в псевдослучайные позиции.

Проект сравнивает влияние этих методов на качество изображений и некоторые статистические характеристики, а также проверяет возможность корректного извлечения сообщения.

## Реализованные методы

### 1. Plain LSB

Сообщение преобразуется в последовательность битов. Каждый бит записывается в младший бит очередной цветовой компоненты изображения.

Перед сообщением сохраняется его длина, что позволяет определить границу полезной нагрузки при извлечении.

### 2. Encrypted LSB

Перед встраиванием сообщение шифруется с помощью AES-256-GCM. Полученный зашифрованный payload последовательно записывается в младшие биты цветовых компонент изображения.

Для получения ключа используется PBKDF2-HMAC-SHA256.

Параметры шифрования:

| Параметр | Значение |
|---|---:|
| Алгоритм | AES-256-GCM |
| Размер ключа | 256 бит |
| Размер соли | 16 байт |
| Размер nonce | 12 байт |
| Размер authentication tag | 16 байт |
| Число итераций PBKDF2 | 600 000 |

Соль и nonce сохраняются вместе с зашифрованными данными, поэтому для расшифрования достаточно исходного пароля и извлечённого payload.

### 3. Encrypted Random LSB

Этот метод использует те же шифрование и формат payload, что и Encrypted LSB, но позиции для встраивания выбираются псевдослучайно.

Последовательность позиций воспроизводится на основе SHA-256 от пароля и генератора случайных чисел NumPy.

Таким образом, для извлечения сообщения необходимо знать пароль и использовать тот же алгоритм выбора позиций.

Псевдослучайное размещение усложняет обнаружение последовательного шаблона встраивания, но само по себе не является дополнительным криптографическим алгоритмом.

## Метрики оценки

Для сравнения исходных и стегоизображений вычисляются следующие показатели.

| Метрика | Назначение |
|---|---|
| MSE | Среднеквадратичная ошибка между изображениями |
| PSNR | Отношение пикового сигнала к шуму |
| SSIM | Структурное сходство изображений |
| Changed components | Число изменённых цветовых компонент |
| Changed ratio | Доля изменённых компонент |
| LSB distribution | Распределение нулей и единиц в младших битах |
| Chi-square | Статистическая оценка отклонения частот пар значений |

Для PSNR используется стандартная формула:

\[
PSNR=10\log_{10}\left(\frac{MAX^2}{MSE}\right),
\]

где для 8-битного изображения \(MAX=255\).

Если сравниваются два идентичных изображения, MSE равна нулю, а PSNR равен бесконечности. Поэтому бесконечное значение в строке исходного изображения (`Cover`) является ожидаемым результатом.

### Статистический анализ χ²

Для анализа LSB используется попарное сравнение частот значений:

\[
(0,1), (2,3), \ldots, (254,255).
\]

Проверяется нулевая гипотеза о равенстве частот двух значений внутри каждой непустой пары.

Число степеней свободы определяется количеством непустых пар. Для вычисления p-value используется верхняя регуляризованная неполная гамма-функция:

\[
p=Q\left(\frac{df}{2},\frac{\chi^2}{2}\right).
\]

Для повышения численной точности при очень малых вероятностях применяется библиотека `mpmath`. Помимо обычного p-value сохраняется его десятичный логарифм `log10_p_value`, поскольку само значение p-value может оказаться слишком малым для представления стандартным типом `float`.

Важно: χ²-тест оценивает конкретное статистическое свойство изображения и не является универсальным средством обнаружения стеганографии.

### Основной эксперимент

```cmd
python run_experiment.py
```


```cmd
python -m unittest test_lsb.py
python -m unittest test_crypto.py
```

## Выводы

- Все три метода позволяют успешно извлекать встроенное сообщение.
- Изменения изображений при небольшом объёме данных остаются визуально малозаметными.
- При увеличении объёма встраиваемых данных MSE возрастает, а PSNR уменьшается.
- Значения SSIM остаются близкими к единице, что указывает на высокое структурное сходство исходных и стегоизображений.
- Шифрование защищает содержимое сообщения, но не устраняет статистические следы встраивания.
- Псевдослучайное размещение меняет характер распределения модифицированных компонент, однако не гарантирует устойчивость к статистическому анализу.
- Результаты χ² зависят не только от метода встраивания, но и от исходного изображения. Поэтому сравнивать их следует с учётом характеристик исходного изображения.
